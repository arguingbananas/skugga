# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub:
**[Report a vulnerability](https://github.com/arguingbananas/skugga/security/advisories/new)**
(the repository's Security tab → "Report a vulnerability").

Please don't open a public issue for security problems. Include what you
found, how to reproduce it, and what an attacker could do with it. You should
get a reply within a week.

## Scope

Skugga is a static browser game with an offline data pipeline. Relevant
reports include, for example, script injection in the viewer or game, problems
in the pipeline's handling of downloaded data, and anything in the repository
that leaks secrets or personal information.

Only the latest commit on `main` is supported.
